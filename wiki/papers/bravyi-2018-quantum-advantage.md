# Quantum Advantage with Shallow Circuits (Bravyi, Gosset & König, 2018)

## Summary

This paper gives the first unconditional, complexity-theoretic proof of quantum advantage: there exists a problem that constant-depth quantum circuits (QNC^0) solve exactly, while any classical probabilistic constant-depth circuit (NC^0) cannot. The separation is unconditional — it does not rely on any unproven complexity conjecture such as P != NP.

The problem is the 2D Hidden Linear Function (2D HLF) problem: given a symmetric matrix A over Z_4 (with zero diagonal), and a vector b over Z_2 satisfying certain linear constraints, find a vector z over Z_2 such that z^T A z + 2b^T z ≡ 0 (mod 4). The quantum circuit solving this has constant depth (specifically 5 layers on a 2D grid of qubits) and uses only Clifford gates, not universal quantum gates.

The classical lower bound is proved using a hybrid argument based on quantum nonlocality. Specifically, the argument reduces classical simulation of the quantum circuit to a classical strategy for a nonlocal game (a multi-party GHZ game and a cycle-graph state game, following Barrett et al.). Classical strategies cannot win these games perfectly, which translates to the impossibility of classical circuits solving the 2D HLF problem at constant depth.

The quantum circuit architecture is a cluster state (graph state) on a 2D grid, followed by adaptive Pauli measurements. Entanglement is generated by CZ gates on nearest-neighbor qubits, giving a physically realistic, near-term implementable circuit.

## Key Claims

- QNC^0 circuits can solve the 2D HLF problem exactly; no NC^0 (or even AC^0 with bounded fan-in AND/OR/NOT) classical circuit of constant depth can
- The separation is unconditional (no complexity conjecture assumed)
- The quantum circuit has depth 5 on a 2D grid, uses only Clifford gates, requires no ancillae beyond the input register
- The classical lower bound uses quantum nonlocality of graph states (GHZ states + Barrett-Pironio-Acin-Gisin-Massar-Sheridan cycle-graph argument)
- The 2D HLF problem is a decision problem related to identifying hidden linear functions in Z_4-valued quadratic forms defined on a 2D lattice graph
- The proof establishes that classical NC^0 circuits fail with probability bounded away from 1 on some input distribution, even allowing randomness

## Methods

- Problem formulation: 2D HLF reduces to a nonlocal game where players (one per qubit) must output consistent parities; the quantum strategy wins perfectly via the graph-state circuit
- Classical lower bound: reduction to nonlocal game impossibility using the GHZ and cycle-graph state nonlocality arguments; Fourier analysis on Boolean functions for depth lower bounds
- Circuit construction: prepare graph state (product of CZ gates on 2D grid) then apply single-qubit Pauli measurements adaptively based on input A and b; total depth constant
- Key technical tool: "lightcone" argument showing each output bit in an NC^0 circuit depends on only a constant-size window of inputs, which is insufficient to compute the required parity globally

## Relevance to Our Work

- The classical lower bound proof rests on quantum nonlocality of graph states, which is the multi-party generalization of the two-party nonlocality used in BPQS (see [[trandafir-cabello-2025-optimal-bpqs]]); KS contextuality underlies both
- Quantum advantage via contextuality/nonlocality connects to the CSW inequality framework ([[algebraic-islands-main]]): contextual advantage in CHSH-type games is the two-party shadow of this multi-party advantage
- The 2D HLF circuit uses only Clifford gates; Clifford circuits are closely related to stabilizer states and the Hesse SIC construction used in [[trandafir-cabello-2025-rigid-ks]]
- This paper motivates the question: can KS sets from our algebraic islands be used to construct similarly efficient nonlocal games or quantum advantage protocols?

## Open Questions

- Can the separation be extended to a larger depth gap (e.g., QNC^1 vs. NC^0, or QNC^0 vs. AC^0)?
- Is the 2D HLF problem a "natural" problem (not constructed specifically for the proof), and does it arise in other computational contexts?
- Do any of our algebraic island KS sets give more efficient (fewer qubits or shallower) quantum advantage circuits?
- Can quantum advantage with shallow circuits be demonstrated experimentally using current hardware?
