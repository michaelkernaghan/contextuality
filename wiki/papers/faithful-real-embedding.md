# Faithful Real Embedding of a Three-Dimensional Complex Kochen-Specker Configuration (Khrennikov & Svozil, 2026)

## Summary

This paper addresses the foundational question of whether quantum theory requires complex Hilbert spaces by giving a KS-type argument distinguishing C^3 from R^3. The main construction is a *phase-adjusted realification*: a procedure that embeds any finite set of rays in C^3 into R^6 while preserving the orthogonality structure exactly (faithful orthogonal representation).

The key tool is the gauge freedom inherent in projective rays. Each ray [psi] in C^3 can be multiplied by any unit phase e^{i*theta} without changing the ray. By choosing these phases inductively — at each step avoiding the finite set of "forbidden" phase values that would introduce spurious orthogonalities — one obtains a set of phases {theta_k} such that two rays are orthogonal in C^3 if and only if their realified images are orthogonal in R^6. The existence of such phases is guaranteed because the forbidden set for each new phase is finite while the unit circle is uncountable; in fact a rational phase assignment with K = 1009 suffices for the 165-ray example.

The paper applies this to the specific 165-ray, 130-context KS configuration in C^3 due to Cabello, built from the four mutually unbiased bases (MUBs) in C^3. This configuration is KS-uncolorable (no two-valued state exists) in C^3 with maximal contexts. After embedding into R^6, the same configuration admits classical two-valued states — one can assign 0 to all 165 rays and 1 to a completion vector in each context — because each 3-element context no longer spans a maximal subspace of R^6. Numerical optimization shows the maximum total valuation across all 130 contexts is at most 128, not 130, confirming the KS obstruction manifests as a global deficit even in R^6.

The paper also provides an explicit table of all 165 rays in C^3 coordinates (using omega = e^{2*pi*i/3}) and their canonical R^6 images.

## Key Claims

- Any finite set of rays in C^3 admits a faithful orthogonal representation in R^6 via phase-adjusted realification
- The 165-ray, 130-context Cabello MUB-based KS configuration is KS-uncolorable in C^3 (maximal contexts) but admits classical two-valued states in R^6 (non-maximal contexts)
- A rational phase assignment with denominator K = 1009 achieves faithful embedding for all 165 rays
- In R^6, the maximum total valuation sum over all 130 contexts is <=128, not 130 (at least 2 contexts must "lose" their value-1 to the complement)
- The separation between real and complex quantum theory appears at the level of logical structure (existence of two-valued states), not just measurement statistics
- The 165-ray configuration coordinates all lie in Q(omega) (the cyclotomic field generated by a primitive cube root of unity)
- In R^3 with maximal contexts, no faithful orthogonal representation exists for this configuration (proven by Harding-Salinas Schmeis and Navara-Svozil)

## Methods

- Phase-adjusted realification: for each ray psi_k, choose phase theta_k to avoid forbidden values; apply canonical map Phi_0(z1,z2,z3) = (Re z1, Re z2, Re z3, Im z1, Im z2, Im z3)
- Inductive phase selection: forbidden set F_m for the m-th ray is a finite union of at most 2-element sets from each nonorthogonal predecessor pair; unit circle minus F_m is non-empty
- Rational phase construction verified by backtracking script confirming K = 1009 suffices
- Admissibility analysis: completeness criterion in R^6 requires assigning value-1 to a basis completion vector outside the 165-ray set; exclusivity is satisfied by orthogonality preservation

## Relevance to Our Work

- The 165-ray configuration uses coordinates in Q(omega), the same cyclotomic field underlying the Eisenstein integer island in [[algebraic-islands-main]]; our 33-vector KS set (CK-33) is a subset of this field's ray pool
- The paper clarifies that faithfulness of a real embedding does not preserve KS-uncolorability when contexts are reinterpreted as maximal in the larger space — this is a subtlety relevant to any attempt to translate our C^3 results to real frameworks
- The MUB structure (4 MUBs in C^3) is the same starting point used in [[trandafir-cabello-2025-rigid-ks]] for the Yu-Oh-Cabello construction; the 165-ray set is a threefold extension of the 13-element Yu-Oh set
- The R^3 impossibility (no faithful orthogonal representation with maximal contexts) is a structural fact about the Eisenstein-integer KS configurations we work with
- See also [[contextuality-logic-probability]] for the logical framework (two-valued states, partial Boolean algebras) used here

## Open Questions

- What is the minimum R^n into which the 165-ray configuration admits a faithful orthogonal representation with maximal contexts that retains KS-uncolorability? (Probably no such n exists by the valuation relaxation argument)
- Does the bound of <=128 for the total valuation sum generalize to a topological or cohomological invariant of the KS hypergraph?
- Is there a practical protocol (self-testing, device-independent cryptography) that exploits the C^3 vs R^6 separation identified here?
- Does the rational phase construction with K = 1009 have a number-theoretic explanation related to Q(omega)?
