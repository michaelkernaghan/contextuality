# Test Note

The Peres-33 set is the smallest known KS set in 3 dimensions with 33 vectors and 16 orthogonal bases. It was discovered by Asher Peres in 1991 and published in Journal of Physics A. The set uses coordinates from the ring Z[sqrt(-2)], making it part of the Heegner-7 algebraic island. Recently, Cabello (2025) found a new 33-vector set with only 14 bases, breaking the basis-count record while matching the vector count.
