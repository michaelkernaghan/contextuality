**Step 1: what the Lean theorems actually establish**

**(a) Roots of unity.**

The statement in [Cyclotomic6n.lean](</C:/Users/Michael Kernaghan/contextuality/lean/Cyclotomic6n.lean:2615>) is:

```lean
theorem six_divides_iff_ks_uncolorable (n : ℕ) (hn : 3 ≤ n) :
    KSUncolorable (S n) ↔ 6 ∣ n := by
```

The paper says:

> “For \(n\ge3\) the theorem is also proved in Lean 4…”

**Match with the stated \(n\ge3\) caveat.** The abstract states that caveat correctly. The Conclusion should repeat it.

The definition is genuinely the coordinate alphabet:

```lean
def rootAlphabet (n : ℕ) (x : ℂ) : Prop := x = 0 ∨ x ^ n = 1
def S (n : ℕ) : Set (Fin 3 → ℂ) :=
  { v | v ≠ 0 ∧ ∀ k, rootAlphabet n (v k) }
```

It is a set of all nonzero alphabet **vectors**, not a projective quotient. That representation difference is harmless for colorability, by the argument below. The \(S_6\) uncolorability proof recomputes its finite constraints and uses the checked refutation; it does not assume Cabello’s result.

For Circle45, every requested check passes:

- **Hypothesis:** \(x\overline{x}=2\) is precisely \(|x|^2=2\), expressed as an equality in \(\mathbb C\).

- **Reduction:** Writing the two linear forms as \(a+bx+c\bar x\) and \(d+ex+f\bar x\), `lmul` returns coefficients
  \[
  (ad+2bf+2ce,\ ae+bd,\ af+cd,\ be,\ cf).

  (a+bx+c\bar x)(d+ex+f\bar x)-\operatorname{eval}(\mathrm{lmul})

  \]
  This is exactly the required identity.

The definitions do not silently weaken the paper’s coloring convention:

```lean
def IsTriad ... :=
  ↑t ⊆ R ∧ t.card = 3 ∧
    ∀ a ∈ t, ∀ b ∈ t, a ≠ b → Orthogonal a b
```

An orthogonal pair outside every triad remains a constraint. `ValidOn` likewise has an unrestricted pair condition and an at-least-one condition on all mutually orthogonal triples; together these impose exactly one.

The possible certificate loopholes listed in the question are closed:

| Suspected loophole | What the source actually does |
|---|---|
| Incomplete pair or triad lists | `Pool.ok` exhaustively checks every in-range orthogonal \(i<j\), and every extension \(j<k\) to a triangle, for list membership. It also checks symmetry and irreflexivity. |
| `colOK` checks only listed pairs | Completeness comes from `Pool.ok`. Extra listed constraints can make acceptance harder; they cannot admit a false coloring of the actual graph. |
| The true mask need not lie inside the colored set | Harmless. The coloring is restricted to the complement of `C`. Every triad entirely inside it must obtain a true vertex inside that triad. Outside true bits cannot satisfy it. Pair checking is actually stronger than necessary. |
| Out-of-range `BT.get` | It does **not** invent an unchecked default leaf. Every natural-number path reaches a real leaf; `BT.get_mem` proves this. All leaves are checked by `BT.all`. |
| Bits at indices \(\ge n\) | Natural-number masks have no truncation or overflow. The actual candidate index set is restricted to indices below \(n\). The soundness proof works with arbitrary masks and cannot create extra candidate rays from high bits. |
| `LB.dead` | It checks that some complement has no remaining element after exclusions. A hitting set avoiding excluded elements cannot meet that complement. This is a valid contradiction leaf. |
| Repeated or inconsistent splits | The checker prevents counting an already included vertex again. The induction follows membership in the actual candidate set; impossible inclusion/exclusion combinations cannot falsify that argument. |
| Infinite \(T\), for which `ncard` behaves differently | `colorable_of_index` first proves the image pool finite and then proves \(T\) finite from the subset hypothesis. No infinite-set loophole remains. |
| Wrong direction of ring injectivity | Lower bounds use **actual orthogonality \(\Rightarrow\) tuple zero** through `h_exact`. Upper bounds use **tuple zero \(\Rightarrow\) actual orthogonality** through `h_sound`. The directions are correct. |

The leaf argument is also correct. If \(I\) contains the already included rays, and \(C_1,\ldots,C_r\) miss \(I\) and become pairwise disjoint after exclusions, a hitting set must contain \(r\) **distinct additional** rays. Thus its size is at least \(|I|+r\). `pack_sound` constructs those additional witnesses; `LB_sound` adds their cardinality to the included set; `min_index` concludes that every smaller candidate lies inside a verified colorable set.

`minimum_eq` proves both halves, rather than merely returning a lower bound. Its selected witness has at most \(u\) vectors; if it had fewer, the already established lower bound would make it colorable. This also explains why a separate no-duplicates condition on the selection is unnecessary.

The injectivity proofs have the required content:

- `not_real` excludes real values for the Heegner, Eisenstein and imaginary-\(\sqrt2\) generators.
- `irrational_sqrt_two` supplies the missing implication for the real Peres field.
- Supergolden `indep` proves independence of \(1,\psi,\psi^2\), using the absence of a rational root.

The negative-control `example`s are meaningful. For each pool they reject the existing tree at \(u+1\), reject the whole pool offered with an all-false coloring, and reject a pair list with its first edge removed. They test actual failure paths. They are supplementary checks, not substitutes for the soundness theorem.

For the Heegner conversion,
\[
a+b\sqrt{-7}=(a-b)+2b\alpha.
\]
Multiplying an entire representative by 1 or 2 is harmless: it preserves its ray and all orthogonality relations. In the current pool-export calculation, all scaling factors were actually 1.

`distinctB` tests **vector equality**, not proportionality. Its comment “No ray is listed twice” is therefore stronger than the predicate itself. This does **not** undermine either minimum claim:

1. A ray coloring pulls back to a coloring of any collection of nonzero representatives.
2. Conversely, choose one representative per ray and restrict a vector coloring to those representatives. Every ray pair or triad lifts to the corresponding vector pair or triad.
3. If a minimum uncolorable vector subset contained two proportional vectors, keeping only one representative of each ray would leave a smaller uncolorable vector subset, contradicting the lower bound.

Thus vector minima and ray minima agree here. The paper should state this argument and acknowledge that this projective interpretation is not itself a theorem in the inspected Lean development. There is no need to suggest that proportional duplicates can defeat the certified minimum.
